# Known issues

Confirmed-but-not-yet-fixed problems that are worth knowing about before
touching related code, tracked by GitHub issue so this file doesn't drift out
of sync with actual status. Keep entries short — this is a pointer list, not
a design doc.

## Adding an entry

1. File a GitHub issue describing the problem, root cause (if known), and
   suspected fix approach.
2. Add a one-line row here linking to it, so anyone (or any Claude session)
   working nearby knows the behavior is a known gap rather than something to
   silently "fix" or work around inconsistently.
3. Remove the row once the issue is closed.

Don't use this file to track personal in-progress investigation or
speculative TODOs — only things confirmed as real bugs with a filed issue.
